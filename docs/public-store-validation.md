## 공유 범위와 시연 데이터

- 수집·명시적 매칭은 public-data 프로필, 시연 점포 생성은 demo-stores 프로필로 분리한다.
- V3는 기존 추천 선점 필드 마이그레이션이다. 이번 공공데이터 수집 키는 V4로 추가한다.
- 사용자용 HTTP API와 기존 JSON 규칙은 변경하지 않는다.
- 보정/동백은 시연 데이터의 구분이다. market_code DB 컬럼이나 새 전체 점포 지도 API는 추가하지 않는다.
- YPAY 컬럼도 stores에 추가하지 않는다. 공공 원본과 참여 점포의 연결은 matched_store_id로 관리한다.
- 등록용 .ids는 SBIZ 원천 external_id다. 다른 개발 환경에서는 먼저 해당 원천을 수집하고 그 환경의 OWNER ID로 등록해야 한다.
- 기존 dongbaek-candidates.ids의 2,045개는 넓은 후보 목록이다. 확정 등록 대상으로 사용하지 않는다. 현재 동백 실행 대상은 dongbaek-verified-buildings.ids의 465개다.
- 상품·가격·준비시간·영업/수령시간은 가상 시연 설정이며 공공데이터에서 확보한 실제 판매 정보가 아니다. 상품명/설명에도 시연임을 표시한다.
- 상품/일정 입력 SQL은 현재 로컬 DB의 stores.id를 기준으로 생성되어 별도 작업 폴더에 있다. 다른 환경의 DB ID가 같다고 가정해 실행하지 않는다. 다른 환경에 재현하려면 그 환경의 원천 연결 및 생성된 점포 ID를 기준으로 다시 준비한다.
- DB에 입력한 데이터가 소스 커밋/푸시만으로 팀원 DB에 복사되는 것은 아니다.
